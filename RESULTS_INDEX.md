# Where the paper's reported numbers come from

Each row is one statement in the paper: what it says, the number it reports, the script
that produced that number, and the starting data files that script needs. Each data file
names the download it arrives in — the archive ships twelve data objects, seven of them
loose and five zipped. Everything else is built by the code in this repository.

**What "how to re-run it" does and does not cover.** The command re-makes the reported
NUMBER from the deposited starting data. It does **not** re-run the upstream tools that
produced that data: SQANTI3's structural classification and Isocall's read assignment ran
before the deposit and ship as files, not as code in this repository. So where a sentence
reads "SQANTI analysis categorized 53.7% of transcripts", the command re-derives the 53.7%
by counting the deposited classification — it does not re-do the classifying. Re-running
those tools means starting from the raw reads in GEO, which is outside this repository's
scope.

Identifiers are `section.paragraph.sentence` — `5.2.1` is section 5, paragraph 2, first
sentence.

**This file is generated** by `tools/build_results_index.py` from the project's records.
In the working repository, do not edit it by hand; the edit would be lost and the records
would still disagree. In the reproduction package it is a fixed view — the generator and
the records it reads are not distributed.

**Coverage: 59 of 149 sentences in the manuscript.** The rest carry no
reported number, or were excluded during triage. That triage is itself under review, because
some excluded sentences do carry numbers.

> **Two columns are incomplete, and marked rather than hidden.** *What was counted* is
> missing on 10 of 59 rows and *how to re-run it* on 4.
> Both are filled from what each script records as it computes a number, so a row is
> blank where its producer does not report one — a figure whose claim is visual, a
> convention such as a significance-star key, or a property of a library rather than an
> output of running it.
> **An empty population must not be read as "the whole dataset"** — it means not
> recorded, and this manuscript's most common defect is a population left unstated.

## Words used in the sentences below

These are the paper's own terms. The sentences are quoted exactly as the paper has
them, so the words are explained here rather than reworded.

- **A5SS** — alternative 5' splice site — the same exon started at a different point
- **AT2** — alveolar type 2 cells
- **AUG** — the start codon — where protein synthesis begins
- **CDS** — coding sequence — the part of a transcript that specifies a protein
- **CNN** — convolutional neural network — a model that learns local sequence patterns by sliding small filters along the sequence
- **CPM** — counts per million — abundance adjusted for how deeply a sample was sequenced
- **DMSO** — the solvent the drug was dissolved in, used as the untreated comparison
- **EJC** — exon junction complex — proteins left behind marking where two exons were joined
- **FB** — fibroblasts
- **FLNC** — full-length non-chimeric reads — long reads judged to span a complete transcript
- **FSM** — full splice match — a transcript whose exon pattern matches a known one exactly
- **GTF** — a text format listing where genes and exons sit on the genome
- **ISM** — incomplete splice match — matches part of a known transcript's exon pattern
- **KEGG** — a database of curated biological pathways
- **LAE** — airway epithelial cells
- **MV** — microvascular endothelial cells
- **NIC** — novel in catalogue — a new transcript built entirely from already-known splice sites
- **NMD** — nonsense-mediated decay — the cell's system for destroying faulty messenger RNAs
- **NNC** — novel not in catalogue — a new transcript using at least one previously unseen splice site
- **OR** — odds ratio — how much more likely something is in one group than another; 1 means no difference
- **ORF** — open reading frame — a stretch that could be read as protein, from a start codon to a stop codon
- **PTC** — premature termination codon — a stop signal appearing earlier in the message than it should
- **RBP** — RNA-binding protein
- **SE** — skipped exon — an exon present in one transcript and absent from another
- **SMG1i** — an inhibitor of the SMG1 kinase — the drug used to switch NMD off (`Smg1i` in the data files)
- **SQANTI** — SQANTI3, the tool that classifies transcripts against a reference annotation
- **SR** — the SR family of splicing-factor proteins
- **SRSF** — SR-family splicing factor — the gene family SRSF1 to SRSF12
- **TES** — transcription end site — where the transcript stops
- **lfsr** — local false sign rate — mashr's posterior probability that the DIRECTION of an effect is wrong; used throughout as the significance cutoff (`lfsr < 0.05`) where a p-value would otherwise be
